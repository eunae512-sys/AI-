# Phase quick-260608-e86 Plan 01: 모델 출연자 광고 품질 + 씬 인식 폴백 Summary

Imagen 정상 경로에 commercial advertising 디렉티브를 더해 광고급 톤을 강화하고, Imagen 실패(쿼터·빌링·프로바이더 부재) 시 gracefulFallback 이 씬을 무시하고 generic 인물을 반환하던 문제를 ModelScene.fallbackQuery + 씬 인식 fetchSceneFromPexels(인물 페널티) 배선으로 해소.

## What Was Built

- **Task 1 (bc07c43):** COMMON_TAIL 앞에 "Professional commercial advertising photography, high detail, sharp focus, polished editorial lighting, premium magazine quality." 1구 추가(기존 익명성·Korean only·no-text 라인 전부 유지). ModelScene 타입에 `fallbackQuery: string` required 추가. 48개 씬 전부 fallbackQuery 작성 — 사물 씬(closeup/overhead/product)은 인물 단어 0, 인물 씬(portrait/lifestyle non-product)은 `korean`+사람+배경. genderDescriptor/ageDescriptor/promptEN 무변경.
- **Task 2 (2c031d0):** demo-images.ts 에 `fetchSceneFromPexels({query, allowPeople, seed})` 신규 export. allowPeople=false 면 alt 인물 키워드 페널티(-50/hit) 후 score>-20 필터, seed 결정적 상위8 변주. API 키 없으면 null. 기존 fetchPortraitFromPexels/portraitQueryForIndustry 시그니처 무손상.
- **Task 3 (5e26797):** route.ts gracefulFallback 이 fallbackQuery 있으면 fetchSceneFromPexels(allowPeople=frame∈[portrait,lifestyle]), 없으면 기존 portrait 폴백. source 라벨 분기. AiModelGenerator POST body 에 scene.fallbackQuery + scene.frame 추가. Imagen 정상 경로·ensurePlanAndQuota/bumpUsage·fortifiedPrompt 전부 무손상.
