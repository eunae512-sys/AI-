## 1. poster-templates.ts — 글자 없는 변환 + 스타일별 텍스트 존
### 1a. COMMON_EDIT_TAIL 교체 (핵심)
- "결과물에는 한국어 라벨·짧은 설명 타이포가 포함될 수 있다." 제거.
- 다음으로 교체: "이미지 안에 어떤 글자·문자·숫자·단어·로고도 그리지 않는다(매우 중요 — AI는 한글을 깨지게 렌더링한다). 텍스트는 나중에 따로 얹으므로, 글자가 들어갈 깨끗한 빈 여백만 확보한다. 단순히 액자/테두리만 씌우지 말고 배경을 깨끗한 화이트로 교체하고 구도를 재배치해 실제로 다르게 보이도록 변환한다."
- 영문 보강 한 줄 덧붙이기(모델 지시 강도↑): "CRITICAL: render NO text, letters, numbers, words, or logos anywhere in the image. Leave clean empty margin space for text to be added later."

### 1b. 각 템플릿 body 에서 글자 지시 제거
- "라벨은 미니멀 타이포로" → "콜아웃 박스와 연결선은 글자 없이 가는 선·도형 그래픽으로만 그리고, 라벨 자리는 빈 칸으로 비워둔다."
- "큰 세리프 헤드라인과 작은 부제를 배치" (magazine cover / stay space) → "헤드라인·부제가 들어갈 위/아래 큰 빈 여백을 확보하되 글자는 넣지 않는다."
- "메뉴 이름과 설명을 타이포로 정리" (menu/price card) → "이름·설명이 들어갈 칸을 가는 헤어라인 구분선으로 잡아두되 글자는 비워둔다."
- 모든 스타일에 "실제로 다르게 보이도록 변환"(배경 화이트 교체·재구도) 취지 반영.

### 1c. 옵션 정리
- PosterStyleOpts 의 signature(이미지에 가게명 텍스트), handwriting(AI 손글씨) 는 더 이상 AI 프롬프트의 "글자 그리기"로 쓰지 않는다. prompt 빌더에서 signature 텍스트 삽입·handwriting AI 타이포 지시 제거(1b/1a 와 충돌). accentColor 는 유지(색감은 글자 아님).
- 스타일별 텍스트 레이아웃 메타 추가: PosterStyle 에 `textZone: "top" | "bottom" | "lower-third"` (cover/space=lower-third or bottom, infographic/menu/card=top). 합성기가 이걸로 위치 결정.

## 2. poster-compositor.ts (신규) — 이미지+텍스트 단일 PNG 합성
- watermark.ts 패턴 재사용. export async function composePoster(opts):
  - 입력: { imageSrc(워터마크 적용 전 AI 이미지 또는 후), title?, subtitle?, zone, handwriting?, accentColor? }.
  - canvas 에 이미지 draw → 텍스트 존(zone)에 따라:
    - title: 명조(Nanum Myeongjo, 없으면 Pretendard) 큰 굵게(짧은 한글 keep-all), 가독 위해 스크림(반투명 그라데이션/박스) 또는 INK 텍스트 on 화이트 여백.
    - subtitle: 작은 보조(INK_SOFT/INK_MUTE).
    - handwriting=true 면 title 만 스크립트/이탤릭 라틴 느낌(한글은 명조 유지 — 철칙: 한글 italic 금지).
  - 한글 가독: 텍스트가 사진 위로 가면 from-black 스크림 또는 PAPER 반투명 박스. 흰 여백 위면 INK 직접.
  - document.fonts.load 로 폰트 보장(타임아웃/실패 시 Pretendard 폴백). 그린 뒤 toDataURL("image/png") 반환.
- 합성 순서: AI 이미지 → composePoster(텍스트) → applyAiWatermark(우하단 라벨). (또는 compositor 안에서 워터마크까지. 단 watermark 재사용 권장 → compositor 는 텍스트만, 호출부에서 watermark 적용.)
- 정직성: 가짜 수치·없는 정보 금지. title/subtitle 은 사용자 입력/브랜드 실데이터만.
