# SUMMARY — 카드뉴스·릴스 문구 휴먼 톤 + 문맥 정합

## 문제 (사용자 보고 2건)
1. 자동 문구가 AI스럽다 → 사람(사장님) 톤으로.
2. 카드뉴스·릴스에 자동 적용되는 텍스트가 문맥이 안 맞는다.

단일 출처: `lib/cardnews/hook-generator.ts` 후킹 풀(hook/problem/value/proof/cta).
릴스 자막은 이 슬라이드 캡션에서 파생되므로 한 곳 고치면 둘 다 반영.

## 휴먼 톤 (`hook-generator.ts`)
- `팔로우 + 알림 ON` → `팔로우해두시면 … 먼저 챙겨드릴게요`
- 영문 DM 트리거 `DM 'OPEN'/'BACK'/'BOOK'/'EVENT' 한 글자` → `디엠 한 줄`·`댓글로`
- `저장각`·`저장 필수`·`꼭 저장하세요` 강박 → 부드러운 권유/제거
- FOMO(`놓치지 마세요`·`지금 아니면 만나기 어려워요`) → 담백한 안내
- CTA 5개 풀(NEW_MENU·SEASON·RETURNING·REVIEW·TREND) 전면 사장님 구어체 재작성

## 문맥 정합성
- **릴스 조각 버그**: 자막 빌더(`CampaignOneLineInput.reelSubtitlesFromGen`)가
  2줄 캡션의 첫 줄만 떼어 "매번 예약을" 같은 조각을 송출 → 두 줄을 한 문장으로
  잇도록 `clip()` 수정.
- 하드코딩 `5월에만 나옵니다` → `timeWord` 반영(시즌 무관 오작동 제거).
- 시즌 FOMO 라인을 공유 `VALUE_POOL` 에서 제거 → 시즌 전용 풀로만. 단골·리뷰·
  트렌드 등 비시즌 캠페인에 계절 문구가 새던 것 차단.

## 검증 (임시 라우트, 검증 후 삭제)
동일 브랜드 3개 토픽 → 카드뉴스 슬라이드/릴스 자막 모두 완결 문장 + 문맥 정합:
- 신메뉴: 봄 먼저 예약 → 단골 우선 → 사장님 직접 → 봄 지나면 한참
- 어버이날: 작년 놓쳤다면 올해 미리 → 단골 우선 → 처음도 단골처럼 → 댓글 인원
- 단골: "이건 진짜 못 참겠다" 단골 말 → 처음도 단골처럼 → 요란하게 안 해도 → 팔로우
- tsc exit 0

## 남은 여지 (선택)
- PROBLEM_POOL 은 종류 비종속(공유) — 단골 캠페인에 "이번 시즌에만 나오는…"
  같은 가벼운 시즌 톤이 드물게 섞일 수 있음. 종류별 PROBLEM 분리는 더 큰 작업.
- buildCaption(인스타 캡션 본문)·해시태그 톤은 이번 범위 밖(슬라이드/자막 우선).
