# Quick Task 260605-ll7 — 카드뉴스 브랜드 로고

## 목표
사장님 브랜드의 **로고 이미지**가 카드뉴스 슬라이드(마스트헤드/콜로폰 + IG 아바타)에
표시되게 한다. 로고가 없으면 워드마크(텍스트) 폴백.

## 현황 진단 (착수 시점)
이미 골격이 아니라 **전체 기능이 구현·배선되어 있었다**:

- **타입** — `components/campaigns/types.ts` `BrandMarkConfig.logoDataUrl?`
- **저장/설정 경로** — `components/campaigns/BrandMarkPicker.tsx` (파일 업로드 → `FileReader`
  → data URL → `saveBrandMark`), 캐러셀 헤더에서 `brandId && brandWordmark` 일 때 노출
- **영속화** — `lib/brand/brand-mark.ts` `loadBrandMark`/`saveBrandMark`
  (brandId 별 localStorage, `briq:brand-mark:{brandId}`)
- **렌더** — `CardnewsCarousel.tsx` `BrandMark` 컴포넌트가 `logoDataUrl` 있으면
  `<img>`(에디토리얼 사이즈: cover ≤48px / inner ≤24px, object-contain, 어두운 배경엔
  `brightness(0) invert(1)` 틴트, 은은한 opacity), 없으면 워드마크 텍스트 폴백.
  5개 컴포지션(masthead·pillar-left·paper-split·overlay-card·type-hero) 모두 호출.
  IG 헤더 아바타도 동일 분기.
- **배선** — `CampaignDraftCard.tsx` 가 `brandId` + `brandWordmark={brandWordmark(brand)}` 전달
- **데모 브랜드** — logoDataUrl 없음 → 워드마크 폴백 (가짜 로고 없음, 의도대로)

→ 신규 구현 불필요. 작업의 실체는 **검증**.
