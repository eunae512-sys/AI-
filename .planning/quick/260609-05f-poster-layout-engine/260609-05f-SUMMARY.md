# Phase quick-260609-05f Plan 01: 포스터 레이아웃 엔진 (전문가 재설계) Summary

사장님 사진 → 포스터 기능을 "AI=사진만 / 앱=디자인 전부" 구조로 재설계 — AI 가 글자·박스 없는 깨끗한 사진 소재를 만들고, 앱 canvas 합성기가 callout/cover/menu 3종 에디토리얼 레이아웃(콜아웃 칩+연결선+진짜 한글 라벨 포함)을 결정론적으로 그린다.

## 아키텍처 (핵심)

★ **AI = 이미지 소재만. 앱 = 모든 디자인·타이포·레이아웃.**

이전 실패: AI 에게 콜아웃·글자를 그리게 함 → (1)한글 깨짐 (2)빈 박스 + 의미 없는 연결선. AI 는 자기가 그린 박스 위치를 앱에 못 알려주므로 텍스트를 채울 수 없었다. 재설계: AI 프롬프트에서 글자·박스·선·그래픽을 전면 금지하고 "깨끗한 사진 소재"만 받는다. 앱 `composePoster` 가 디자인 토큰으로 제목·부제·콜아웃 칩+연결선+SAGE 끝점+라벨·메뉴 리스트 전부를 직접 그린다. → 텍스트 항상 정확, 위치 통제, 온브랜드, 정직.

## 레이아웃별 동작 (15스타일 → 3엔진)

- **callout** (6스타일, 핵심): 배경 PAPER 풀캔버스 → 상단 명조 제목+부제+SAGE 룰 → 사진을 중앙 카드(폭 62%, RULE 헤어라인)로 배치 → 콜아웃 라벨 2~4개를 사진 좌우 여백에 결정론적 균형 배치(2=좌상/우하, 3·4=코너), 각 칩(PAPER+RULE 사각, SAGE 마커+한글 라벨)에서 사진 가장자리로 얇은 연결선 + SAGE 끝점. **빈 라벨 칩은 자동 제외(빈 박스 0)**, 겹침 0.
- **cover** (4스타일): AI 히어로 사진 풀블리드 → 하단 transparent→INK 스크림(50%) → 영문 eyebrow(자간, 라틴 대문자) + 큰 명조 헤드라인(PAPER) + SAGE 룰 + 부제. 매거진 표지 톤.
- **menu** (5스타일): 상단 사진 50% → 하단 PAPER 영역에 명조 제목+부제+SAGE 룰 → 메뉴 행(이름=명조 INK, 설명=INK_MUTE 우측정렬, 행 사이 RULE_SOFT 헤어라인). 가격/수치 임의 생성 없음.

모두 토큰(INK/SAGE/RULE/PAPER), 명조 헤드라인/Pretendard 본문, 한글 upright(italic 금지), keep-all, 사각·헤어라인.

## PosterStudio 편집 UI

- style.layout 별 편집 필드 분기: callout=제목/부제+라벨 2~4칸(+/- 추가삭제, signatureMenu 프리필), cover=헤드라인/부제, menu=메뉴 행(이름+설명, signatureMenu 프리필).

- "이 포스터 사용" → composePoster(layout, content) → applyAiWatermark → onGenerated.
