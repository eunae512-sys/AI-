## 2. poster-compositor.ts — 레이아웃 엔진(전문가 품질)
`export type PosterContent = { title?; subtitle?; callouts?: {label:string}[]; menuItems?: {name:string; desc?:string}[]; caption?: string; accentColor?; handwriting?: boolean };`
`export async function composePoster(opts: { imageSrc, layout: PosterLayout, content: PosterContent }): Promise<string>` — canvas 합성, PNG 반환. 공통: high-DPI(예 1080×1920), ensureFonts, drawImage, 모든 텍스트 keep-all 줄바꿈, 토큰 색.

### 2a. layout="callout" (핵심 — 현재 깨진 것)
- 배경 PAPER(#FAF7EE) 풀캔버스. AI 사진을 중앙 카드로 배치(상하 여백 확보, 예 가로 70~78% 폭, RULE 1px 헤어라인 테두리, 사각).
- 상단: 제목(Nanum Myeongjo, INK, 큰, keep-all) + 부제(INK_MUTE 작게) + 그 아래 짧은 SAGE rule(2px, 폭 작게).
- 콜아웃 칩 2~4개(content.callouts): 사진 카드 좌우 여백 또는 코너에 균형 배치. 각 칩 = 작은 사각(PAPER 위 RULE 헤어라인), 안에 라벨(Pretendard 또는 명조, INK, 작게, keep-all). 칩에서 사진 쪽으로 가는 얇은 연결선(RULE 또는 SAGE 0.5~1px) + 사진 가장자리 끝점에 작은 SAGE 점(3px). 칩 위치는 결정론적 균형 배치(예 2개=좌상/우하, 3개=좌상/우상/하중앙, 4개=네 코너) — 절대 겹치지 않게.
- 인셋(선택, 품질 여유 시): 일부 칩에 사진의 한 영역을 원형/사각으로 크롭해 작게 넣기(ctx.drawImage 소스 사각 크롭). 시간 없으면 라벨 칩만으로도 충분 — 빈 박스는 절대 금지(라벨 없으면 그 칩 안 그림).
- 콜아웃 개수 = content.callouts.length(0이면 칩 없이 제목만). 라벨은 실데이터(시그니처 메뉴)·사용자 편집.

### 2b. layout="cover"
- AI 히어로 사진 풀블리드. 하단 from-transparent→INK(투명도) 스크림(높이 ~45%). 그 위 하단 정렬: (선택)영문 eyebrow(브랜드, Cormorant/대문자 자간 — 라틴만), 큰 명조 헤드라인(PAPER 텍스트, keep-all), 부제(PAPER 80%), 얇은 SAGE/PAPER rule. 매거진 표지 톤.

### 2c. layout="menu"
- 상단 ~52~58% AI 사진(사각). 하단 PAPER 영역: 제목(명조 INK) + 메뉴 리스트(content.menuItems: 각 행 = 이름(INK 중간) ···· 짧은 설명(INK_MUTE), 행 사이 RULE_SOFT 헤어라인 구분선). 가격/수치 임의 생성 금지(없으면 표기 안 함).

품질 바: 여백·정렬·자간·라인 두께가 매거진 수준. 칩/선/텍스트 겹침 0. 작은 화면에서도 라벨 가독.
