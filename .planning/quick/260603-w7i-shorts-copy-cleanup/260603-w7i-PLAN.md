# Quick Task 260603-w7i: 쇼츠(/shorts) 페이지 이름·문구 정리

## Problem

`/shorts` 페이지는 실제로 **멀티 플랫폼 홍보 카피 생성기**(사진 1장 → 인스타·틱톡·유튜브쇼츠·네이버플레이스 카피 일괄 생성)인데, 문구가 영상 편집기처럼 오해를 준다:
- Topbar breadcrumb `"릴스·틱톡·쇼츠 한 번에"` → 영상을 만드는 것처럼 읽힘
- pipeline의 `"쇼츠 직접 편집"` → 쇼츠 영상 편집기처럼 읽힘

릴스(`/reels`, 영상 편집기)와의 혼동 제거가 목적. **텍스트/카피만 수정, 로직 변경 없음.**

## Tasks

### Task 1 — 쇼츠 페이지 이름·문구 명확화
- **files:** `briq-app/app/(app)/shorts/page.tsx`, `briq-app/app/(app)/pipeline/page.tsx`
- **action:**
  - `shorts/page.tsx` metadata.title → `"BRIQ · AI 자동 홍보 (멀티 플랫폼 카피)"`
  - `shorts/page.tsx` Topbar breadcrumb `"릴스·틱톡·쇼츠 한 번에"` → `"사진 한 장 → 플랫폼별 홍보 카피 한 번에"`
  - `pipeline/page.tsx` DIRECT_EDIT label `"쇼츠 직접 편집"` → `"플랫폼별 홍보 카피 생성"`
- **verify:** `tsc --noEmit` 통과, 문자열 3건 반영 확인
- **done:** 쇼츠가 영상 편집기가 아니라 멀티플랫폼 카피 생성기임이 페이지 이름·breadcrumb·파이프라인 링크에서 드러남

## Must-haves
- 쇼츠 페이지 토픽바·메타·파이프라인 라벨이 "카피 생성"임을 명시
- 영상 편집 뉘앙스("쇼츠 직접 편집", "한 번에"의 영상 함의) 제거
- 타입체크 통과 (로직 무변경)
