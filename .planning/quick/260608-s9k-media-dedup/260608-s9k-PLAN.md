## A. 카드뉴스 사진 중복 제거 (핵심·필수)

### A1. CardnewsCarousel.tsx 이미지 로드 useEffect를 2-pass distinct 배정으로 교체
파일: briq-app/components/campaigns/CardnewsCarousel.tsx (현 라인 ~256-292)

요구:
- 1차(병렬): 각 슬라이드마다 `/api/search-pexels` 호출하되 body에 `returnCandidates: true, candidateCount: 9, perPage: 30` 추가. 응답에서 후보 url 배열 추출 (`data.candidates.map(c => c.url).filter(Boolean)`, 없으면 `data.image` 단일). 슬라이드별 후보 풀 배열 `pools: string[][]` 구성.
- 2차(단일 동기 패스): `const used = new Set<string>()`. 슬라이드 순서대로:
  - 자기 풀에서 `used`에 없는 첫 url을 픽. 없으면 전역 풀(`pools.flat()`)에서 `used`에 없는 첫 url.
  - 픽 성공 시 `used.add(pick)`.
- state 반영: 기존 가드 유지 — `existing.cover && !existing.cover.startsWith("http")` 이면 보존(업로드 data URL). 그 외 cover를 배정된 url로 교체. 배정 실패(undefined) 슬라이드는 기존 cover 유지.
- `cancelled` 플래그 cleanup 유지. 의존성 배열 `[slideContentKey, industry, brandId]` 유지.
- eslint-disable 주석 유지.

주의: 병렬 fetch 결과를 모두 받은 뒤(2차 패스) 한 번에 `setSlides` — race 방지. 부분 실패한 슬라이드(빈 풀)는 건너뛰고 나머지는 distinct 배정.

### A2. search-pexels 실 Pexels 경로 결정적 픽 (방어)
파일: briq-app/app/api/search-pexels/route.ts (라인 220-227)
