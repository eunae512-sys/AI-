## 2. ShortsScreen.tsx — 편집 가능 + 자막 필드
### 2a. 편집 state
- updateResult(platform: PlatformId, patch: Partial<PlatformOutput>) 추가 → setResults(prev => prev.map(r => r.platform===platform ? {...r, ...patch} : r)).
- PlatformCard 에 onUpdate?: (patch: Partial<PlatformOutput>)=>void prop 추가, 호출부(라인 ~560 map)에서 onUpdate={(patch)=>updateResult(r.platform, patch)} 전달.

### 2b. FieldBlock 편집 가능화
- FieldBlock 에 optional onChange?: (v:string)=>void 추가. onChange 있으면 읽기전용 div 대신 편집 가능 요소 렌더: multiline 이면 textarea, 아니면 input(또는 한 줄 textarea). 토큰 정합(RULE 보더·INK·사각·bg PAPER 계열), 포커스 스타일 절제. charCount 는 live value.length. 복사 버튼 유지.
- 제목: onChange={(v)=>onUpdate?.({title:v})}. 본문: onChange={(v)=>onUpdate?.({caption:v})}.

### 2c. 자막(subtitle) 필드 신설
- PlatformCard body(제목 위 또는 아래)에 FieldBlock 추가: label="자막 (영상 위 문구)", value=result.subtitle, onChange={(v)=>onUpdate?.({subtitle:v})}, 복사 가능. naver 는 자막 미사용이면 숨겨도 됨(meta.id!=="naver" 일 때만 노출 — 미리보기와 일치).
- 편집 시 PlatformCard 번인 미리보기(result.subtitle 사용)가 라이브 갱신되는지 확인(포스터 isPoster 분기 무손상).

### 2d. 무손상
- regenerate/다시 작성은 setResults 로 새 카피 덮어씀(편집 초기화) — 정상. 복사/전체복사/예약/해시태그/포스터 번인 억제(직전 fix) 보존.
