# Phase quick-260608-u44 Plan 01: 내 사진 → AI 에디토리얼 포스터 Summary

소상공인이 올린 **실제 가게 사진**을 Nano Banana(gemini-2.5-flash-image) image-to-image 로 편집해 업종별 에디토리얼 포스터(흰 배경 플랫레이 · 디테일 콜아웃 박스 + 얇은 연결선 + 재료 인셋 + 미니멀 타이포)로 다듬는 기능. 가짜 사람 생성과 정반대 — 진짜 피사체를 살려 신뢰를 지킨다.

## 무엇을 만들었나

### (a) 백엔드 — image-to-image 편집 + 라우트 (commit b4b5586)
- `lib/ai/image/types.ts`: `ImageGenInput.inputImage?: string` 옵셔널 추가 (data URL 또는 https URL). 없으면 기존 text-only 동작 그대로 — 회귀 없음.
- `lib/ai/image/gemini.ts`: Nano Banana 분기가 `inputImage` 있으면 `contents: [{inlineData}, {text}]` 로 편집. `toInlineData()` 헬퍼가 data URL → 정규식 추출, https URL → fetch+base64+content-type. Imagen 분기 무변경.
- `lib/ai/image/index.ts`: `getEditProvider()` 추가 — Nano Banana 고정 반환. 기존 `selectImageProviderChain` 무변경.
- `app/api/generate-poster/route.ts` (신규): runtime nodejs. body `{ inputImage, prompt, size, styleId, slideId }`. `ensurePlanAndQuota({feature:"ai-image:generate", usage:{kind:"aiImage"}})` 게이팅(generate-image 동일), 비로그인 통과(userId=null). **no-text 강화 미부착** (프롬프트 템플릿 그대로). 성공 시 `persistImage`+`bumpUsage`. 키 미설정/한도/플랜 거절/실패 → `ok:false` + 친절 한국어 안내 (원본 둔갑 금지, 정직성 #7). `generate-image/route.ts` 미변경.

### (b) 업종별 포스터 템플릿(기준) (commit 2347c60)
- `lib/ai-gen/poster-templates.ts` (신규): `PosterStyle` 타입 + `getPosterStyles(industry)`. 업종 6종 총 **15 스타일** (restaurant 3 / cafe 3 / dessert 3 / beauty 2 / stay 2 / local 2).
- 대표 스타일 = 사용자 예시(흰 배경 플랫레이 에디토리얼 인포그래픽). `COMMON_EDIT_TAIL` 이 실제 피사체 유지·화이트 미니멀 매거진·9:16·타이포 허용을 못 박음. 옵션 `accentColor`/`handwriting`/`signature` 지원.
- 정직성: 프롬프트가 "없는 메뉴·가짜 수치·가짜 후기 금지" 를 명시.

### (c) PosterStudio UI + 호스트 연결 (commit 5b86751)
- `components/ai-gen/PosterStudio.tsx` (신규): 업로드(data URL)→스타일 픽커→강조색 스와치+손글씨 토글(접이식)→POST /api/generate-poster→`applyAiWatermark`→9:16 미리보기→`onGenerated`. SAGE/INK/RULE/PAPER 토큰, 사각 헤어라인 카드, 솔리드 잉크 버튼. 실패 시 toast 안내(원본 둔갑 안 함).
- `ShortsScreen.tsx`: `SourceMode` 에 `"poster"` 추가, 세 번째 탭 "내 사진 → 포스터" (Sparkles 아이콘, SAGE), `onGenerated` → `setFile({aiGenerated:true, aiSceneTitle:"AI 포스터"})`.

## 검증 결과

1. **tsc**: `./node_modules/.bin/tsc --noEmit -p tsconfig.json` → **통과 (exit 0)**, 매 단계 확인.
2. **라이브 백엔드 (필수)**: Pexels 한식 사진(다크 우드 테이블 한 상)을 base64 로 Nano Banana 에 restaurant 에디토리얼 인포그래픽 프롬프트와 함께 직접 호출 → **12.2초 만에 ok + 1.5MB PNG**. `/tmp/poster-result.png` 저장 후 Read 육안 확인:
   - 흰 배경 9:16 플랫레이 포스터
   - 디테일 콜아웃 박스 + 얇은 연결선이 각 요리를 가리킴
   - 한국어 라벨(윤안당·김치·칼국수·양념치지 등) + 짧은 설명 타이포
   - 원본의 실제 요리가 보존·인식 가능
   - de-risk 증명 재현 확인. (어댑터와 동일한 inlineData 호출 경로 — 임시 probe 실행 후 삭제)
3. **/shorts 헤드리스 Chrome + CDP**: "내 사진 → 포스터" 탭 클릭 → PosterStudio 렌더(`hasStudio:true`). 파일 업로드(DOM.setFileInputFiles) 후 스타일 카드 **3개** 렌더 + 강조색 옵션 노출 확인. 스크린샷 2장 육안: 사각 헤어라인 카드·SAGE 액센트·솔리드 잉크 버튼·KFTC 라벨 안내. SaaS 색 없음.
4. **grep (신규 3파일)**: `violet|emerald|tone="sky"|tone="amber"|rounded-(xl|2xl)` → 실사용 **0건** (유일 매치는 PosterStudio 주석의 금지 규칙 문구). 포스터 프롬프트 가짜 수치/후기 0건 (수치는 "지어내지 않는다" 가드와 동반).
5. **회귀**: `generate-image/route.ts` 미변경. `inputImage` 는 옵셔널이라 text-only 호출(AiModelGenerator 등) 동작 불변 — tsc 통과로 시그니처 호환 확인.

## ReelsScreen 연결 — 후속(deferred)

플랜상 ReelsScreen 연결은 선택. 이번 범위에서는 **ShortsScreen 만** 연결했다. ReelsScreen 은 컷/자막/BGM 등 별도 상태 모델이라 동일 패턴 적용 시 추가 검토가 필요해 위험을 낮추려 보류. 후속 작업에서 ShortsScreen 과 동일한 `sourceMode="poster"` + PosterStudio 패턴으로 추가 가능.
